# STILL sounds: rules for agents

- Public repo (`Tafazzolian/still-sounds`) holding the files STILL downloads; see `README.md` for names and credits.
- Every file must be free to redistribute (CC0 or an equivalent licence); record the source and licence in `README.md`.
- File names follow STILL's catalog (`../still/src/main/assets/ambient/catalog.json`); renaming one breaks downloads for installed apps.
- Loop tools: `make-loop.sh`, `loop-opus.py` (seam fix), `check-loop.py`.
- Push through the repo-local credential helper; never `gh auth switch`.
